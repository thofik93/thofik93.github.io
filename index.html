Highlights

Work I'm proud of

A few results from the last few years, taken from my commit history.

iOS · Android · Web
One app, four platforms

I've been on Lilla since its third week. One React Native/Expo codebase serves the iOS app, the Android app and the desktop and mobile web through react-native-web, across about 80 native and 86 web screens.

SDK 43 → 55
Platform upgrades

I led Expo upgrades from SDK 43 to 49 and from 53 to 55 (React Native 0.79 → 0.83). I turned on the New Architecture and Hermes, and kept the app meeting the Android 14 and 16 store requirements.

0.8–2s → fast
Best-voucher engine

It automatically picks the best voucher across caps, flash sales and "super vouchers", so the price on the product page matches the price at checkout. I also fixed the lookup latency with indexing and a refactor.

Vector + BM25
Hybrid semantic search

Product search on Elasticsearch with kNN embeddings. Query-intent detection sends exact brand or product queries to keyword ranking. Indonesian synonyms go live within minutes, without a deploy.

3 marketplaces
Shopee, Tokopedia, TikTok Shop

Catalog sync, order import, shipping labels and token refresh. Built on RabbitMQ workers so the brand can sell everywhere from one back office.

1-tap
Buy Now checkout

A one-step express checkout across the cart, voucher, shipping and order services, with in-store pickup, map pin-point addresses and delivery-time estimates.
